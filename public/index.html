Java 入力

クラスや main は不要です。一文ずつ書いて実行できます。

使える文
  • 移動(数字); 矢印の方向へ進む（1マス＝40、マイナスで後ろへ下がる）
  • 向く("A"); 地点（"A"〜"F"）の方向へ矢印を向ける（※ヒヨコ・爆弾・靴・ゴールには直接向けません）
  • 向く(数字); 今の向きから指定した角度だけ回す（90 で右へ90度、-90 で左へ90度）
  • 部位回転("部位名", 数字); 手足を回す（腕を回してヒヨコに触れると自動で掴みます ※爆弾に触れるとゲームオーバー）
  • 掴む(); 近くのヒヨコを掴む ／ 離す(); 持っているヒヨコをその場に離す
  • 靴を履く(); 近くの靴を履く（すべての靴を履くと針山を通れます）
  • while (条件) { ... } 条件を満たしている間、{ } の中を繰り返す（例：while (近くにいない("A")) { 移動(30); }）
  • 繰り返し(数字回) { ... } 指定した回数だけ { } の中を繰り返す
  • もし (条件) { ... } そうでなければ { ... } 条件に合うかどうかで動きを分ける
  • 【条件】 近くにいる("対象") ／ 近くにいない("対象")
    対象には地点（"A"〜"F"）のほか、"ゴール", "ヒヨコ", "爆弾", "靴" を指定できます
